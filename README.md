Write your Devlog here. :3
The TreeOfBirds script is added to the Tree GameObject, which makes the sparrows pop out when the player enters a certain distance. Basically, the script is inputed an array (Bird[] _sparrow) to appear in the inspector, so you can add the sparrow in. For each sparrow, the script also uses vectors to help measure the distance from the player, and it calculates that distance. Once the player reaches a certain distance, it will play a pop-up animation from all the sparrow GameObject.
